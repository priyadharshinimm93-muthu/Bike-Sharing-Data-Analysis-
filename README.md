Bike Sharing Data Analysis

Project Overview

This project analyzes bike sharing data to understand usage patterns, station performance, and revenue trends. The analysis helps identify high-performing and underperforming stations and cities, supporting data-driven decision-making.

Objectives

- Analyze bike usage across stations and cities  
- Measure total distance and revenue  
- Evaluate station utilization  
- Compare year-over-year performance  
- Identify underperforming stations  

Dataset Description

The dataset includes bike trip details such as:

- Date of trip  
- Station name  
- City  
- Distance traveled  
- Revenue  
- Year and month  

Data cleaning and transformation were performed before analysis.

Tools Used

- Excel – Data cleaning and preparation  
- Power BI – Data modeling, DAX calculations, and dashboard creation  

Data Model

A star schema was used for efficient analysis:

- Fact Table: Distance, Revenue, Operating Cost  
- Dimension Tables: Station, City, Date  

Analysis Performed

- Descriptive analysis to summarize usage and revenue  
- Diagnostic analysis to understand performance differences  
- Trend analysis to compare yearly performance  
- Station and city-wise efficiency analysis  

Key Insights

- A few stations generate the highest distance and revenue  
- Some cities show steady growth over time  
- Underutilized stations indicate improvement opportunities  
- Bike usage varies by year and location  

Dashboard Highlights

- KPI cards for total distance and revenue  
- Station utilization percentage  
- Year-over-year growth comparison  
- Interactive slicers for city, station, and year  

Conclusion

This project demonstrates end-to-end data analysis skills, including data cleaning, modeling, visualization, and insight generation. It is suitable for showcasing Power BI and analytical skills in a data analyst portfolio.
